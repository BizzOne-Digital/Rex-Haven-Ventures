# Rex Haven Ventures
## Simple Admin Dashboard Guide

This guide explains how to manage the website from the admin dashboard. It focuses on the everyday actions you will use: adding, editing, publishing, hiding, reviewing, and deleting.

## Opening the Dashboard

1. Open the [Admin login page](https://rex-haven-ventures-6dg9.vercel.app/admin/login).
2. Enter your administrator email address.
3. Enter your password.
4. Select **Sign in**.

After signing in, the dashboard menu appears on the left. On a phone, select the menu button to open it.

## What the Menu Does

- **Dashboard**: Shows a quick summary of the website.
- **Blog Posts**: Shows all existing blog posts.
- **Create Blog**: Lets you write a new blog post.
- **Categories**: Organises blog posts into groups.
- **Services**: Manages the services shown on the website.
- **Members**: Shows people who have created an account.
- **Feedback & Insights**: Shows comments and ideas waiting for review.
- **Media**: Stores images for the website.
- **Profile & Settings**: Lets you change your name or password and sign out.

## Save, Publish, Hide, and Delete

- **Save draft**: Saves your work, but visitors cannot see it.
- **Publish**: Saves your work and makes it visible on the website.
- **Unpublish**: Removes something from the website but keeps it in the dashboard.
- **Delete**: Removes something permanently.

When unsure, choose **Save draft** or **Unpublish** instead of **Delete**.

## Dashboard Home

The Dashboard shows the number of submissions waiting for review, published posts, drafts, members, categories, and images. It also shows recent activity.

Select **Refresh** if the numbers look out of date.

## Blog Posts

Select **Blog Posts** to view existing articles. Use the search box to find a post by title. You can also select **All**, **Published**, or **Drafts**.

### Edit an Existing Post

1. Select **Blog Posts**.
2. Find the post.
3. Select **Edit**.
4. Change the information you need to change.
5. Select **Preview** to check how it looks.
6. Select **Save & keep live** if it is already public and should stay public.
7. Select **Save draft** if you are not ready for visitors to see the changes.

### Publish a Draft

1. Open **Blog Posts**.
2. Find the post marked **Draft**.
3. Select **Edit** or **Publish**.
4. Check the post carefully.
5. Select **Publish**.

The post will then be visible on the website.

### Hide a Post Without Deleting It

1. Open **Blog Posts**.
2. Find the published post.
3. Select **Unpublish**.

The post will be hidden from visitors and kept in the dashboard.

### Delete a Post

1. Open **Blog Posts**.
2. Find the post.
3. Select **Delete**.
4. Read the warning.
5. Select **Delete permanently** only if you no longer need the post.

If you only want to hide the post, select **Unpublish** instead.

## Add a New Blog Post

1. Select **Create Blog**, or select **New post** on the Blog Posts page.
2. Enter the post title.
3. Add a short summary.
4. Write or paste the article into the main text box.
5. Choose a category.
6. Add the author name.
7. Check the publication date.
8. Add the reading time, or select **Estimate from body**.
9. Add a featured image if needed. You can upload one or choose one from the Media library.
10. Add tags if needed, separated by commas.
11. Select **Preview** and read through the post.
12. Select **Save draft** to keep it private, or **Publish** to make it public.

### Feature a Blog Post

While editing a post, select **Feature this post at the top of the blog**. Only one post can be featured at a time. Choosing a new featured post removes the featured label from the previous one.

## Categories

Categories help organise blog posts.

### Add a Category

1. Select **Categories**.
2. Select **New category**.
3. Enter the category name.
4. Add a short description if needed.
5. Select **Create category**.

### Edit a Category

1. Select **Categories**.
2. Select the edit button beside the category.
3. Change the name or description.
4. Select **Save changes**.

Changing a category name also changes it on the blog posts that use it.

### Delete a Category

1. Select **Categories**.
2. Select the delete button beside the category.
3. If the category is being used, choose another category for those posts.
4. Confirm the deletion.

Do not delete a category if you are unsure where its blog posts should go.

## Services

Select **Services** to manage the services shown on the homepage and Services page.

### Edit a Service

1. Select **Services**.
2. Find the service you want to change.
3. Select the edit button.
4. Change the name, description, image, button text, or other information.
5. Check the visibility options.
6. Select **Save changes**.

### Add a New Service

1. Select **Services**.
2. Select **New service**.
3. Enter the service name and tagline.
4. Add the short and full descriptions.
5. Explain what the service involves and who it is for.
6. Add the button text and the page the button should open.
7. Add an image if needed.
8. Choose the display order.
9. Select **Create service**.

### Show or Hide a Service

There are two separate options:

- **Published**: Turn this on to show the service on the website. Turn it off to hide it everywhere.
- **Show in the homepage grid**: Turn this on to show the service on the homepage. Turn it off to keep the service on the Services page but remove it from the homepage.

For a service to appear on the homepage, both options must be turned on.

### Delete a Service

1. Select **Services**.
2. Find the service.
3. Select the delete button.
4. Read the warning.
5. Confirm only if the service should be permanently removed.

To hide a service temporarily, turn off **Published** instead of deleting it.

## Feedback & Insights

Members can send feedback and insights about blog posts. New submissions are private until you approve them.

Select **Feedback & Insights** to see the submissions waiting for review.

### Approve and Publish a Submission

1. Open **Feedback & Insights**.
2. Read the submission.
3. Check which blog post it relates to.
4. Select **Approve & publish**.

The submission will then appear on the related blog post for visitors to read.

### Decline a Submission

1. Select **Decline**.
2. Add a short explanation if needed.
3. Select **Confirm decline**.

The member can see the explanation in their account.

### Return a Submission to the Review List

If you approved or declined something by mistake:

1. Find it under **Approved** or **Rejected**.
2. Select **Return to queue**.

It will go back to the waiting list.

### Delete a Submission

1. Select **Delete** beside the submission.
2. Read the warning.
3. Select **Delete permanently** only if it should be removed completely.

If you simply do not want it shown publicly, select **Decline** instead.

## Members

Select **Members** to view people who have registered on the website. You can search by name or email address and filter members by account type or status.

### Deactivate a Member

Deactivating a member stops them from signing in or sending new submissions, but keeps their existing information.

1. Find the member.
2. Select the active/deactivate option.
3. Confirm the change.

### Reactivate a Member

1. Filter the list to show deactivated members.
2. Find the member.
3. Select the activate option.

The member will be able to sign in again.

### Change a Member to an Administrator

Only give administrator access to someone who should be trusted to manage the entire website.

1. Open **Members**.
2. Find the member.
3. Change their role to **Administrator**.
4. Confirm the change.

Administrators can edit website content, manage members, approve submissions, and change settings.

### Delete a Member

1. Find the member.
2. Select **Delete**.
3. Read the warning carefully.
4. Confirm only if the account and its submissions should be permanently removed.

Deleting a member also removes their submissions.

## Media and Images

Select **Media** to upload and manage images.

### Upload an Image

1. Select **Media**.
2. Select the file chooser under **Upload an image**.
3. Choose one or more images from your computer.
4. Wait for the upload to finish.
5. The images will appear in the Media library.

The page shows which image types and sizes are accepted.

### Add an Image to a Blog Post

1. Open or create a blog post.
2. Find the **Featured image** section.
3. Select **Choose from library**.
4. Find the image.
5. Select **Use this**.
6. Save the blog post.

You can also select **Upload image** from inside the blog editor.

### Delete an Image

1. Select **Media**.
2. Find the image.
3. Select the delete button.
4. Check whether the image is being used by a blog post.
5. Confirm only if you are sure.

Deleting an image that is being used can remove it from the blog post as well. When unsure, select **Cancel**.

## Profile & Settings

Select **Profile & Settings** to manage your administrator account.

### Change Your Name

1. Enter the new name under **Display name**.
2. Select **Save name**.

### Change Your Password

1. Enter your current password.
2. Enter your new password.
3. Enter it again in **Confirm new password**.
4. Select **Change password**.

Keep your password private. Do not send it to anyone by email or message.

### Sign Out

1. Select **Logout** at the bottom of the left menu, or open **Profile & Settings** and select **Sign out**.
2. Sign out whenever you finish, especially on a shared computer.

## If You Make a Mistake

- If a blog post is public by mistake, select **Unpublish** immediately.
- If a service is public by mistake, turn off **Published**.
- If a submission was approved by mistake, find it under **Approved** and select **Return to queue**.
- If you have not saved a change yet, leave the page without saving.
- If you deleted something by mistake, contact the person who manages the website as soon as possible.

## Quick Daily Checklist

1. Sign in at the admin login page.
2. Check the **Awaiting review** number on the Dashboard.
3. Review new items under **Feedback & Insights**.
4. Check blog posts that need editing or publishing.
5. Preview important changes before publishing.
6. Visit the public website to check major changes.
7. Select **Logout** when finished.

## Remember

- Save as a draft when you are still working.
- Preview before publishing.
- Unpublish when you want to hide something but keep it.
- Delete only when you are certain it is no longer needed.
- Ask for help before deleting anything important.
